# Electrician Website Template

One-page React/Vite demo site for a fictional electrician business: **Northline Electrical**.

## Quick Customize

Most client-specific content lives near the top of `src/main.jsx`:

- `business`: company name, phone number, service area, hours, rating
- `services`: three main service cards
- `gallery`: three image-led project cards
- `testimonials`: customer review cards

Main design styling lives in `src/styles.css`. This version follows the
Belashed Beauty Bar demo layout baseline and does not include the WebGL element.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production files are created in `dist/`.
